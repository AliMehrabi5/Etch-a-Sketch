# Etch-a-Sketch

A browser-based Etch-a-Sketch game built with HTML, CSS, and JavaScript as part of The Odin Project Foundations curriculum.

## Features

- Dynamic grid generation based on user input.
- Customizable grid size from 1×1 to 100×100.
- Flexbox layout for responsive square grids.
- Random RGB color for each square.
- Progressive color darkening as the mouse passes over squares.
- **New Grid** button to create a new grid at any time.
- Input validation to prevent invalid grid sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- DOM Manipulation
- Event Listeners

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/AliMehrabi5/etch-a-sketch.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter the desired number of squares per side.
5. Move your mouse over the squares to draw with random colors.
6. Click **New Grid** to create a new grid.
